# v0.0.32

One-line change to the generated markdown. The "What you'll learn" teaser list
now separates a step's title from its note with a spaced hyphen instead of an
em-dash.

## Changed

- **`Demo.Markdown()` renders the teaser list as `- **Title** - note`** rather
  than `- **Title** — note`. Consumers that regenerate a walkthrough will see
  one changed character per step in the "What you'll learn" block; nothing else
  in the rendered document moves, and no API changes.

## Why

Projects that keep their generated walkthroughs free of em-dashes could not do
so, because this one line was the only remaining source of them and it lives
here rather than in the consumer's own strings. mcpkit hit this while purging
em-dashes from its published docs: 99 of them, across twelve generated
`WALKTHROUGH.md` files, all traced back to this `Fprintf`.

## Upgrading

Bump the dependency and regenerate:

```bash
go get github.com/panyam/demokit@v0.0.32
make readme     # or: go run . --doc md > WALKTHROUGH.md
```

The regenerated file will differ by one character per step. Commit it alongside
the bump so any CI drift check stays green.
