# v0.0.33

Dependency bump. demokit now builds against servicekit v0.2.0. No demokit API
changes.

## Changed

- **servicekit v0.1.1 to v0.2.0** (PR 76). servicekit v0.2.0 renames
  `ConnId`/`ConnIdStr` to `ConnID`/`ConnIDStr`; the `web` package's live
  connection code is updated to match. servicekit is used only inside `web`,
  so nothing demokit exports changes.
- **Smaller dependency graph.** servicekit v0.2.0 no longer pulls in grpc,
  genproto or protobuf, so they drop out of demokit's `go.mod`. The bump also
  picks up gorilla/websocket v1.5.3 and newer golang.org/x/sync, sys and text.

## Upgrading

```bash
go get github.com/panyam/demokit@v0.0.33
go mod tidy
```

Minimum version selection will move your module to servicekit v0.2.0 as well.
If your own code imports servicekit and calls `ConnId()` or sets `ConnIdStr`,
rename those to `ConnID()` and `ConnIDStr`.

The notebook module is tagged `notebook/v0.0.33` alongside, with no changes.
